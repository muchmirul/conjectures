4 · Measure any table in people per color

The scoring rule behind the whole question: a table's rate is the number that, multiplied by itself once per color, gives the table size.

Try this. Set size 5 at 2 colors and read 2.24. Set size 16 at 3 colors and read 2.52. Then push the size as high as you like and watch how slowly the rate responds: rates are hard currency.

Erdős offered 250 dollars for what the best rate approaches and 100 dollars for whether it is even finite. The 2026 answer: it climbs forever.
